# DrLinq | دکترلینک

**پروژه اصلی و فعال فعلی**

DrLinq یک بازار سراسری خدمات درمانی غیر اورژانسی برای اتصال نیاز واقعی بیمار به ارائه‌دهندگان مناسب است.

## هسته محصول
بیمار نیاز خود را ثبت می‌کند → سیستم درخواست را ساختاربندی می‌کند → ارائه‌دهندگان مناسب Match می‌شوند → ارائه‌دهنده اعلام آمادگی می‌کند → بیمار گزینه مناسب را انتخاب می‌کند → ارتباط دو طرف برقرار می‌شود.

## دامنه
- تمام تخصص‌های پزشکی غیر اورژانسی
- دندانپزشکی
- آزمایشگاه و تصویربرداری
- توانبخشی و خدمات مرتبط

## زبان
- فارسی: زبان پایه
- عربی: زبان بعدی هدف برای بیماران خارج از ایران و گردشگری درمانی
